# 🛡️ WB Competitor Sentinel

Готовое B2B-решение для селлеров Wildberries, позволяющее автоматически отслеживать изменение цен и акции конкурентов.

## 💡 Продуктовая аналитика & Монетизация

### Проблема
Селлеры на маркетплейсах теряют до 20% выручки из-за того, что конкуренты снижают цены, а селлеры узнают об этом слишком поздно и выпадают из выдачи.

### Решение
Легкий Telegram-бот, который опрашивает публичный API Wildberries без авторизации каждые 5 минут и присылает Push-уведомление, когда конкурент снижает цену ниже заданного порога.

### Бизнес-модель (Freemium SaaS):
* **Free**: Отслеживание до 2 товаров, проверка раз в час.
* **PRO (990 ₽/мес)**: До 50 товаров, интервал 5 минут, истории изменений цен.
* **Agency (2990 ₽/мес)**: До 300 товаров, экспорт в Excel, алерт в командный чат.

## 🚀 Быстрый запуск

1. Клонируйте репозиторий и установите зависимости:
```bash
pip install -r requirements.txt
```

2. Получите токен бота у [@BotFather](https://t.me/BotFather) в Telegram.

3. Вставьте ваш токен в переменную `BOT_TOKEN` в файле `main.py`.

4. Запустите бота:
```bash
python main.py
```

## 🛠 Стек технологий
* **Language:** Python 3.11+
* **Framework:** aiogram 3.x (AsyncIO Telegram Bot Engine)
* **Network:** aiohttp (High-performance async HTTP Client)
* **Data Sources:** Wildberries Public Internal Endpoint (Card API v2)
